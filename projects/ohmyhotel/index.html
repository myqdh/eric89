Boarding · case study 01 — Background

Understanding the product

Ohmyhotel is a B2C travel platform for desktop and mobile, helping users book hotels and plan trips across multiple Asian markets. The product is part of the Ohmyhotel&Co travel technology ecosystem.

Pain points

  • There was no shared design system, which led to inconsistent fonts, colors, spacing, component sizes, and UI patterns across web and mobile. This slowed down the design process and made product updates more difficult.
  • The website was quite simple and not flexible enough to support different marketing campaigns, promotions, and content needs.
  • Several UI and usability issues affected the overall experience and consistency across devices.

Project goals

  • Build a shared design system with reusable components and clear guidelines to improve consistency, speed up the design process, simplify future updates, and reduce UI errors across web and mobile.
  • Optimize and redesign the existing interface to create a smoother, clearer, and more consistent user experience.
  • Create flexible layouts and components to better support marketing campaigns, promotions, and content across different Asian markets.

ISSUE-01 Resolved

Mobile Search

Problem

On mobile, pressing the "Go" key after entering a hotel name did not start the search. Users had to tap the "Apply" button instead, adding an extra step.

What I did

I found the issue while testing the search flow and proposed using the "Go" key to trigger the same action as the "Apply" button. I then worked with developers to implement the fix.

Result

The search flow became faster and more natural for mobile users.

ISSUE-02 Resolved

Confirmation Popup

Problem

The booking confirmation popup used both "Cancel" and "Close," which could confuse users about what each action would do.

What I did

I identified the issue while testing the checkout flow and proposed clearer actions, such as "Cancel booking" and "Continue editing.".

Result

The new labels made the actions easier to understand and reduced the risk of users selecting the wrong option.

Gate · Design 04 — Design Solution

Search experience across web & mobile

A look at how the core hotel search experience was redesigned across desktop and mobile, from starting a search to browsing results.

Fig. 01Desktop — Home

Home

The main search fields — destination, dates, and guests — are grouped together at the top of the page.

WHY

This helps users quickly understand what information they need and start searching with fewer steps.

Fig. 02Desktop — Search Results

Search Results

Search details, filters, sorting, and hotel results are organized in one view for easier browsing and comparison.

WHY

This helps users narrow down their options and compare hotels without moving between multiple screens.

Fig. 03Mobile — Home

Home

Destination, dates, and guests are grouped into a simple search area designed for smaller screens.

WHY

This keeps the main search action clear and easy to use on mobile.

Fig. 04Mobile — Search Results

Search Results

Key hotel information such as images, ratings, benefits, and prices is prioritized for quick scanning.

WHY

This helps users compare options quickly while keeping the amount of information manageable on a smaller screen.
